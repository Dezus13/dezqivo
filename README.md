# DEZQIVO

> DEZQIVO — интеллект, который превращает слова в действия.

DEZQIVO создаётся как единый AI-агент, который понимает намерение пользователя и контролируемо превращает его в понятный результат или разрешённое действие.

## Статус

- Этап: `0 — Документационный фундамент`
- Состояние этапа: `completed`
- Продуктовая реализация: не начата
- Текущий активный план: отсутствует
- Завершённый план: [PLAN-0001: Документационный фундамент](plans/completed/plan-0001-документационный-фундамент.md)

Наличие документа, этапа или возможности не означает, что соответствующая функция уже реализована или поддерживается.

## Назначение репозитория

Репозиторий хранит документы — источники истины, утверждённые планы и документированные результаты развития DEZQIVO. Программная реализация появляется только на основании применимых утверждённых требований и плана.

`README.md` служит короткой точкой входа и не заменяет документы, на которые ссылается.
